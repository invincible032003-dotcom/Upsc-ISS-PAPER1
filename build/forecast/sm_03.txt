X Var(X^2) = E(X^4) - 1 = 2, and the same for Y^2.
X Corr = 2 rho^2/2 = rho^2, option (b).

@ FS-101 | Bivariate Normal Distribution | Regression Lines
Q In a bivariate normal, X and the residual Y - E(Y given X) are
O uncorrelated but dependent
O independent
O perfectly correlated
O identically distributed
A b
S The residual is a linear combination of jointly normal variables and is uncorrelated with X, hence independent of it.
T Inside a joint normal family, uncorrelated upgrades to independent - that is the whole reason the decomposition is so useful.
T This is exactly why the conditional variance does not depend on x.
X The residual Y - mu_2 - b_yx(X - mu_1) is a linear function of X and Y, hence jointly normal with X.
X Its covariance with X is 0.
X For jointly normal variables that means independence, option (b).

@ FS-102 | Bivariate Normal Distribution | Independence and Linear Combinations
Q X is N(0,1) and Z is N(0,3), independent, and Y = X + Z. What is Corr(X, Y)?
O 1/4
O 1/2
O 1/sqrt(3)
O 1/3
A b
S Cov = 1 and Var(Y) = 4, so the correlation is 1/2.
T Adding independent noise reduces the correlation to sd(signal)/sd(total).
T The variances add, so Var(Y) = 4 and sd(Y) = 2 - not sqrt(3).
X Cov(X, Y) = Var(X) = 1.
X Var(Y) = 1 + 3 = 4.
X Corr = 1/sqrt(1 x 4) = 1/2, option (b).

@ FS-103 | Bivariate Normal Distribution | Marginal Distributions
Q If rho equals plus or minus 1 in a bivariate normal, then
O the joint density still exists
O the distribution is degenerate and has no joint density
O X and Y are independent
O rho is undefined
A b
S The covariance matrix becomes singular, so the mass concentrates on a line and no two-dimensional density exists.
T The normalising constant carries 1/sqrt(1 - rho^2), which blows up as |rho| tends to 1.
T The distribution still exists - it is simply singular, supported on a straight line.
X At |rho| = 1 the determinant of the covariance matrix is 0.
X The distribution then puts all its mass on a line in the plane.
X There is no joint density, option (b).
